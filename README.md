AI models that detect Leishmania parasites in microscope images work well in the lab that trained them, but lose much of their accuracy when used in a new lab, country or microscope. Nobody knows how much local data is needed to make them safe again.

How many labelled local images does a Leishmania detector need to recover reliable performance at a new site, which type of model needs the fewest, and can the model recognise when it should hand an image to a human?

The first benchmark that tests detectors across all four public Leishmania datasets on sites they have never seen, measures how performance recovers as local images are added, and evaluates whether the models can flag uncertain cases for human review.
